# Карьера в Синергиум

Сайт-визитка компании Синергиум для кандидатов. На одной странице собраны рассказ о компании, её ценности, преимущества работы, условия и адаптация новых сотрудников.

## Структура

```
index.html   — разметка и тексты страницы
styles.css   — оформление и адаптивная вёрстка
script.js    — анимации, мобильное меню, счётчики
assets/      — логотип и фотографии
```

Сайт статический, без сборки и зависимостей. Шрифт Manrope подключается из Google Fonts.

## Разделы страницы

1. Первый экран: заголовок, основатель компании и ключевые цифры
2. О компании
3. Почему у нас классно работать
4. Масштабные задачи
5. Команда
6. Адаптация новых сотрудников
7. Условия работы
8. Жизнь за пределами работы и удалённая работа
9. Ценности и главный принцип
10. Финальный призыв присоединиться к команде

## Локальный просмотр

Откройте `index.html` в браузере или запустите любой статический сервер в папке проекта, например:

```bash
npx serve .
```

## Публикация на GitHub Pages

1. Загрузите файлы в репозиторий.
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`.
4. Нажмите **Save**. Через пару минут сайт будет доступен по адресу вида `https://<имя-пользователя>.github.io/<название-репозитория>/`.

## Редактирование

- Тексты находятся в `index.html`.
- Фирменный цвет `#90db00` и другие цвета задаются переменными в начале `styles.css` (блок `:root`).
- Фотографии лежат в `assets/`. При замене сохраните имя файла или обновите путь в `index.html`.
